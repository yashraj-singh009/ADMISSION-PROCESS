# Project Statement: Admission Process System

## Problem Statement
Educational institutions need a simple and reliable way to manage student admissions. Manual record-keeping can make registration, fee calculation, student searches, and marks management slow and error-prone.

## Project Objective
The **Admission Process System** is a menu-driven Python application designed to organize essential admission-related tasks in one place. It allows users to register students, generate unique registration numbers, calculate fees according to class, search student records, assign marks, and view stored information.

## Main Features
- Register students with personal and parent details.
- Validate mobile numbers, email addresses, age, class, and marks.
- Generate a unique registration number in the format `26ST0001`.
- Calculate fees automatically:
  - Classes 1 to 5: Rs. 20,000
  - Classes 6 to 8: Rs. 30,000
  - Classes 9 to 12: Rs. 35,000
- Search for a student using the registration number.
- Assign marks for CHY, PHY, MAT, CSE, and ENG.
- Display one or all registered student records.
- View class-wise and student-specific fee information.

## Scope
This project is suitable as a basic school admission-management program. Student information is stored temporarily in a Python dictionary while the program is running. It demonstrates functions, loops, conditional statements, dictionaries, input validation, and exception handling.

## Expected Outcome
The system provides a clear and user-friendly method for handling admission records. It reduces repetitive manual work, improves data accuracy, and makes student details easier to access.
